## 🚀 ¿Qué se puede hacer con el proyecto?
Esta aplicación permite gestionar eventos dentro de una comunidad de manera eficiente, ofreciendo las siguientes funcionalidades:

* **Autenticación de Usuarios:** Registro e inicio de sesión seguro para los miembros de la comunidad.
* **Gestión de Eventos:** Creación, edición y visualización detallada de eventos comunitarios.
* **Sistema de Comentarios:** Interacción entre usuarios a través de comentarios en cada evento.
* **Historial:** Seguimiento de eventos pasados y actividades realizadas.
* **Estadísticas:** Panel visual con métricas y datos relevantes sobre la participación y gestión de eventos.

## 🛠️ Tecnologías Utilizadas
El proyecto ha sido construido utilizando estándares modernos de desarrollo para Android:

* **Lenguaje:** [Kotlin 2.2.10](https://kotlinlang.org/)
* **Interfaz de Usuario:** [Jetpack Compose](https://developer.android.com/jetpack/compose) con **Material Design 3**.
* **Arquitectura:** Recomendada por Google para aplicaciones modernas de Android.
* **Gestor de Dependencias:** Gradle con Version Catalogs (Kotlin DSL).

---

## 📋 Requerimientos del Sistema
Para poder ejecutar o modificar este proyecto, necesitarás:

* **Android Studio:** Versión Ladybug (2024.2.1) o superior (debido a la versión de AGP 9.2.1).
* **JDK:** Versión 11 o superior.
* **SDK de Android:**
    * `minSdk`: 24 (Android 7.0 Nougat)
    * `targetSdk`: 36
* **Dispositivo:** Android físico o emulador con API level 24 o mayor.
